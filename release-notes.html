RELEASE NOTES

What’s new in Wires

Discover the new features and main fixes included in each version.

LATEST VERSION

Wires 1.3.0

Released August 24, 2026

What’s New

  • New full-screen view for positioning connection points more precisely.
  • Optional numbering for a device's connection points.
  • Enhanced Category/Cable/Zone filters: isolate or hide, with individual control per item.
  • Each signal route can now be hidden independently of the others.
  • Zones and text labels can now be copied and pasted.
  • Each connector's type now displays while adding a cable.
  • Interactive HTML export: Category/Cable/Zone filters are now complete, just like in the app.

Fixes

  • Fixed the license purchase link blocking discount code entry.

PREVIOUS VERSION

Wires 1.2.0

Released August 15, 2026

What’s New

  • Wires now automatically lets you know when a new version is available.

Fixes

  • Security improvements.

PREVIOUS VERSION

Wires 1.1.0

Released August 14, 2026

What’s New

  • Interactive guide to get started with Wires from your very first project
  • Wireless connections (WiFi, Bluetooth, HF) — document links with no physical cable
  • A route can now have multiple signal types at once (e.g. Video + Audio)
  • Right-click to copy/paste a route segment
  • Automatic numbering for identical devices (same image = same model)
  • Edit a device already placed on the canvas, no need to recreate it
  • Drag and drop a route or path to reorganize it in one move
  • Animate every route at once, or a single segment, with a double-click
  • Pause animation playback with the space bar
  • Export
    • Optional cable length, included in the Pack List export
    • HTML export: live preview of your project before exporting
    • Pack List export: real generation, grouped by category or zone, with assignable people in charge
    • Routes PDF export completely redesigned, with a route map
    • Portrait/Landscape orientation for PDF exports

Fixes

  • Deleting a device now actually deletes its cables too
  • Cables now route around neighboring devices more cleanly while dragging
  • Smoother route animation, no more stuttering
  • The minimap no longer shows full color for content outside the visible area
  • Several fixes in the export window (closing too early, icons, etc.)
