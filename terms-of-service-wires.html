Scope

These Terms of Service define the conditions under which Wires may be downloaded, installed, activated and used. They apply to Wires Free, to the paid plans, to Wires Cloud and to the referral program.

Software presentation

Wires is professional software for documenting and planning audiovisual signal architectures. It allows users to place devices on a canvas, connect them with cables, organize those connections into signal routes and generate interactive or printable documentation.

License, plans and versions

Wires is distributed as a single desktop application. Without a license key, it runs as Wires Free, free of charge and with no time limit. A license key unlocks, in the same application, the features of the plan purchased:

  • Wires Fast: a 30-day license, paid once, for a single computer. It includes every Wires feature except Wires Cloud. It ends by itself after 30 days, with no renewal.
  • Wires Pro: a one-year subscription, for one person on up to two computers. It includes Wires Cloud.
  • Wires Ent.: a one-year subscription, for up to ten computers. It includes Wires Cloud.

Subscriptions renew automatically at the end of each year, and the renewal can be cancelled at any time; the subscription then stays active until the end of the period already paid. New versions of Wires are included for the duration of the license. Payment, invoices, renewal and its cancellation are handled by Lemon Squeezy, the reseller of Wires.

When a license ends, Wires returns to Wires Free. Projects saved on the computer can still be opened; only the features of the plan are no longer available. What happens to Wires Cloud projects is described in the Wires Cloud section.

The limits of Wires Free and the details of each plan are those shown on the official product page at the time of purchase.

One-time-payment Wires Pro licenses: Wires Pro licenses purchased before version 1.6.0 remain valid, with no time limit and no subscription, for all 1.x versions of Wires. Later major versions (2.0.0 and beyond) require a new license.

Activation and license key

The license key is personal, non-exclusive and non-transferable. A Wires Pro key may be used by the same person on two computers; a Wires Fast key, on one; a Wires Ent. key, on up to ten computers within a single organization. It may not be resold, rented, shared publicly or distributed.

Wires Cloud

Wires Cloud is an online service included in the Wires Pro and Wires Ent. plans. It lets users save projects online, open them again from another computer and share them. Projects saved on the computer remain ordinary files: Wires Cloud adds to them, it does not replace them. The available space is 2 GB per Wires Pro license and 20 GB per Wires Ent. license.

Username. On first use, the user chooses a username. It is visible to the people the user shares projects with, and on the page of a Wires Cloud link. It must not impersonate anyone or be offensive.

Sharing. A project can be shared with other Wires Cloud users, designated by their username; they accept or decline it. The owner can withdraw their access at any time. The owner can also create a Wires Cloud link, valid for 7 days, to send to anyone. This link opens a page from which the latest saved version of the project can be downloaded, as well as Wires. The owner alone is responsible for distributing this link and may delete it at any time.

Content. The user remains the sole owner of, and solely responsible for, the projects and images saved or shared in Wires Cloud. The user guarantees holding the rights to them and undertakes not to place any unlawful or infringing content there, or any content that violates the rights of others.

Moderation. Alkoda On Air hosts Wires Cloud projects. For security, support or legal compliance reasons, or following a report, Alkoda On Air may view, block or delete a project. A blocked project is no longer accessible, either to its owner or to the people it was shared with, and its Wires Cloud link is deleted. Every viewing and every action is recorded.

Trash. A project deleted by its owner stays in the Wires Cloud trash for 30 days, from which it can be restored; it is then permanently deleted.

End of license. When a Wires Pro or Wires Ent. license ends, Wires Cloud projects are no longer accessible, and they are permanently deleted 30 days later. Wires notifies the user before a cancelled subscription ends, leaving time to save the projects to the computer. A subscription resumed with the same email address before deletion gets its projects back.

Availability. Wires Cloud is provided as is. Alkoda On Air strives to keep it available and to preserve the data, without being able to guarantee it. Keeping a copy of important projects on the computer is recommended.

Referrals

The referral program lets a Wires Pro or Wires Ent. subscriber (the referrer) introduce Wires to a new person (the referred user), and both receive free months of subscription.

Referral code. Each Wires Pro or Wires Ent. license has a referral code, shown in the License window of Wires. A code can be used only once: after each successful referral, a new code replaces it. Wires Pro licenses purchased before version 1.6.0 also have a code.

Conditions. The referral program applies to a new Wires Pro or Wires Ent. subscription, taken out from the License window of Wires after entering the code. A purchase made elsewhere, in particular from the website or the online store, does not qualify. The code cannot be used by the referrer, nor on a computer where the referrer's license is activated. Wires Fast is not part of the referral program.

Free months. The number of free months depends on the referrer's and the referred user's plans, according to the scale shown in Wires and on the plans page. They are added 15 days after the referred user's subscription, provided it has been paid and not refunded, and they push back the next payment date of each subscription concerned. For a Wires Pro license purchased before version 1.6.0, they are added to the Wires Cloud access. If the referrer's subscription is no longer active on that date, the referrer's free months are lost. Free months have no cash value: they cannot be exchanged, refunded or transferred.
