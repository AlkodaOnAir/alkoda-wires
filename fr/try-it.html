New Device · New Cable · Add Text Label · Add Zone
Modification d'un appareil
Cliquer sur le nom de l'appareil

Le renommer, saisir le nouveau nom et appuyer sur Entrée.

Double-cliquer sur l'appareil

Ouvrir la configuration de l'image pour modifier son image et ses ports.

Faire glisser l'appareil

Déplacer l'appareil sur le canevas.

Faire glisser son coin supérieur gauche

Redimensionner l'appareil proportionnellement.

Maj+clic sur l'appareil

Mettre l'appareil au premier plan, devant tout appareil qui le chevauche.

Utiliser l'icône corbeille rouge du panneau Info pour supprimer cet appareil.

Modifier un chemin de câble
Faire glisser un segment

Le déplacer perpendiculairement pour ajuster le chemin.

Clic droit près d'un appareil

Ouvrir le menu « Change direction / Create bend ».

←→↑↓

Après « Change direction » : modifier la direction de sortie du segment.

←→↑↓

Après « Create bend » : insérer un coude à 90°.

Animer une route
Double-cliquer sur une route ou un câble

Lancer l'animation du signal.

Espace

Mettre en pause ou reprendre l'animation.

Sélectionner plusieurs appareils
Alt+cliquer et glisser

Dessiner un rectangle : tous les appareils qu'il touche sont sélectionnés.

Windows Ctrl+clic sur l'appareil Mac ⌘+clic sur l'appareil

Cliquer sur un appareil sélectionné

Cliquer sur le canevas

Esc
